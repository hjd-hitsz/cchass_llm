# Xiangqi-R1：通过强化学习提升大语言模型在中国象棋中的空间战略推理能力

Yuhao Chen, Shuochen Liu, Yuanjie Lyu, Chao Zhang, Jiayao Shi, Tong Xu\* 中国科学技术大学 isyuhaochen@mail.ustc.edu.cn tongxu@ustc.edu.cn

## 摘要

长期以来，游戏一直是评估通用人工智能的基本基准。虽然大语言模型（LLM）在一般推理方面表现出了令人印象深刻的能力，但其在空间策略推理方面的有效性（这对于复杂且完全可观察的棋盘游戏至关重要）仍未得到充分探索。在这项工作中，由于其复杂的规则和空间复杂性，我们采用中国象棋作为具有挑战性和丰富的测试平台。为了提高法学硕士在此类环境中的战略能力，我们提出了一个专为象棋量身定制的训练框架，该框架建立在包含 500 万个棋盘对的大规模数据集上，并通过专家注释和引擎评估进行了增强。在此基础上，我们推出 Xiangqi-R1，一个以多阶段方式训练的 7B 参数模型。我们的实验结果表明，尽管通用法学硕士规模庞大、能力强大，但它们仍难以在这些任务中取得令人满意的表现。与通用法学硕士相比， Xiangqi-R1 移动合法性提高了 18%，分析准确性提高了 22%，取得了巨大进步。我们的结果指出了在复杂领域创建通用战略情报的一条有前途的道路。 <sup>1</sup>

## 1 简介

长期以来，玩游戏一直是评估智力的关键基准，尤其是在追求通用人工智能 (AGI) 方面。近年来，大语言模型（LLM）表现出了卓越的通用推理能力，在广泛的任务中取得了与人类专家相当甚至超过的性能 (Guo et al., 2025; Yang et al., 2025)。然而，它们在涉及基于空间规则的推理和战略决策的完全可观察的战略游戏任务中的能力仍未得到充分验证。这一差距对法学硕士迈向更通用的人工智能构成了重大挑战。此类任务要求模型既能理解复杂的规则，又能根据当前的董事会制定合理的战略、合法的举措。我们将这些综合能力统称为空间策略推理。该术语指的是模型准确解释 2D 棋盘状态结构、执行有效分析并仅基于文本输入生成操作的能力，如图 1 所示。

克服这一挑战的努力主要集中在探索监督微调（SFT）方法来改善游戏中的着法生成。国际象棋领域取得了显著进展，包括 ChessGPT 等开创性作品 (Feng et al., 2023), 国际象棋法学硕士 (Zhang et al., 2025c)，和伴侣 (Wang et al., 2025)。尽管取得了这些进展，这些研究仍然存在与空间策略推理相关的两个关键局限性。一个限制在于建模层面，另一个限制在于评估层面。首先，之前的工作主要集中在国际象棋作为评估领域。虽然有用，但其规则的几何形状可以允许模型在不深入了解空间约束的情况下生成合法的移动。我们认为中国象棋是一个更具挑战性和信息量更大的测试平台。与国际象棋相比，象棋的棋盘更大（9x10），棋子种类更多（7个），并且空间限制更严格（例如九宫）。这些因素需要对董事会结构和空间推理有更深入的了解。其次，SFT 提高了生成输出的召回率和结构一致性 (Chu et al., 2025)。然而，在静态游戏数据集上训练的 SFT 模型往往会记住训练模式，而不是发展真正的战略理解，这会导致在新的棋盘状态中遇到困难，并且在不熟悉的情况下无法识别最佳动作。

为了解决这些研究空白，我们引入了象棋的综合数据集，并提出了一个针对该领域量身定制的推理模型，名为 Xiangqi-R1。在数据集构建方面，我们从开源象棋平台收集了专业的对弈记录，构建了包含 500 万个棋局对的大规模数据集。此外，我们还策划了数以万计的高质量注释样本，包括人类专家撰写的走法注释和优势评估以及 Pikafish 引擎生成的最佳走法注释 (Pikafish Developers, 2025)，提供丰富的语义和策略信息来支持高级推理任务。

为了有效利用这些数据，特别是语义丰富且复杂的评论内容（如图1所示），我们提出了一个多阶段的训练框架来增强LLM的游戏推理能力：（1）基于大规模合法棋步数据进行微调，以增强模型对空间规则的理解； （2）融合专家评论和引擎注释数据，提高模型的董事会状态评估和战略解释能力； （3）引入使用少量数据并具有多维度奖励（移动奖励、分析奖励和格式奖励）的强化学习（RL）机制，通过策略优化来增强模型在复杂博弈中的推理稳定性。

实验结果验证了我们方法的有效性。尽管 7B 参数规模不大， Xiangqi-R1 在空间战略推理的多个关键指标上，其性能显著优于通用模型数倍。例如，与强模型相比 Doubao-Pro-1.5-Think (Seed et al., 2025)，移动合法性指标（legal@1）提高了18%，董事会评估准确性（3-class@1）提高了22%，表明我们的方法显著增强了模型在这种情况下的空间策略推理能力。总之，这项研究做出了三个关键贡献：

1) 我们引入了第一个针对象棋的评估框架，该框架全面评估法学硕士在不同游戏阶段和棋子类型中的空间策略推理，从而实现细粒度的表现分析。

2) 我们提出了一种集成专家知识、引擎注释和多维强化学习奖励机制的训练策略，以增强模型的空间策略推理能力。

3) 实验结果表明，尽管只有 7B 个参数， Xiangqi-R1 在象棋空间推理方面超越了较大的普通法学硕士，表现出卓越的推理能力和策略适应性。

## 2 相关工作

## 2.1 人工智能在类国际象棋游戏中的应用

人工智能的发展重塑了国际象棋等传统棋类游戏，使其成为战略推理的试验台和算法创新的平台。从深蓝的强力搜索和手工评估函数到 Stockfish的 α-β 剪枝和精细启发式方法，该领域已从原始计算转向更复杂的建模 (Campbell et al., 2002; Stockfish Developers, 2025)。受到阿尔法狗的启发 (Silver et al., 2016) 和阿尔法零 (Silver et al., 2017)，国际象棋社区集成了神经网络评估模块（例如 NNUE），催生了像 Pikafish 这样的混合引擎 (Pikafish Developers, 2025) 将深度特征提取与经典搜索相结合，改善复杂位置的决策。随着国际象棋引擎现在超越人类的能力，研究已经从人类竞争转向使用游戏任务来评估通用人工智能中的规划、因果推理和结构泛化。

最近的研究已经开始探索法学硕士与国际象棋的整合，以检验其在顺序决策和结构理解方面的潜力。 ChessGPT 等系统 (Feng et al., 2023), 国际象棋法学硕士 (Zhang et al., 2025c)，和伴侣 (Wang et al., 2025) 通过SFT整合专家走法、引擎评估和战术注释，在战略走法生成和评估方面取得了初步成功。在此基础上，我们将法学硕士的架构扩展到象棋，解决其独特的空间限制和不对称规则。我们的方法显示出在复杂、规则密集的环境中提高的理解力和适应性，有助于一般战略情报的研究。

## 2.2 法学硕士推理的强化学习

强化学习在增强法学硕士在数学、代码生成等各个领域的推理能力方面表现出了巨大的潜力 (Zhang et al., 2025a; Chen et al., 2025; Zhang et al., 2025b; Lin et al., 2025; Liu et al., 2025)。这些任务通常需要复杂的、多步骤的决策过程，这对传统的 SFT 提出了巨大的挑战。最初，来自人类反馈的强化学习 (RLHF) (Christiano et al., 2017; Ouyang et al., 2022) 引入是为了使模型输出与人类偏好保持一致，解决纯监督方法的局限性。解决诸如近端策略优化（PPO）之类的 ActorCritic 方法的复杂性 (Schulman et al., 2017)，更有效的替代方案已经出现。直接偏好优化 (DPO) (Rafailov et al., 2023) 通过消除批评者成分来简化训练，尽管其非策略性质限制了泛化。

最近，GRPO (Shao et al., 2024) 通过增强的优势估计技术提高了训练稳定性。尽管取得了这些进展，但基于强化学习的方法在空间策略推理任务中仍未得到充分探索，特别是在国际象棋和象棋等复杂领域。在这项工作中，我们通过纳入专家指导的奖励函数来扩展 GRPO，旨在利用 RL 克服先前仅 SFT 方法固有的局限性，并推进这一关键但不发达领域的研究。

## 3.1 初步

在介绍我们的方法之前，我们概述了象棋、棋盘和走法表示、Pikafish 引擎以及必要的定义，以方便理解。

象棋。象棋是一种传统的两人、完全可观察的零和游戏，在由中央河划分的 9×10 网格上进行。河牌将棋盘分开并限制某些棋子的移动。每方的后方中心各有一个3×3的宫殿，限制着国王和卫兵。有七种棋子类型，每种类型都有独特的移动规则。有关棋子移动规则的全面描述，请参见附录 B。

董事会代表。表示象棋位置的最简单方法是使用名为 BoardStr 的字符串，该字符串直观且易于理解。便携式游戏符号（PGN）记录整个移动序列，使其更适合计算机处理，但不太关注当前位置。 Forsyth-Edwards Notation (FEN) 在一行中有效地描述了整个棋盘状态和要移动的一侧，如图 1 所示。在我们的实验中，BoardStr 和 FEN 都用作模型输入来提高位置理解。

移动表示。移动描述了一个棋子从一个位置到另一个位置的过渡。中文文件格式 (CFF) 使用四个汉字，对于人类来说很直观，但对于计算机来说并不理想。互联网中国象棋服务器（ICCS）格式通过起始和结束坐标表示走法，使其更适合计算机处理，并且是计算机系统中最早使用的格式之一。

皮卡鱼。 Pikafish 是一款开源高性能象棋引擎，Elo 评级为 3954，远高于人类最高水平 2800 左右，它被用作我们的地面实况参考。它支持快速搜索和评估，符合标准象棋协议，并且给定搜索深度或时间以及FEN格式的位置，返回最佳走法和位置评估：

$$
\text { BestMove }, \text { Value } = \text { Pikafish(Cfg,FEN) }.\tag{1}
$$

为了方便起见，红色的评估分数为正，黑色的评估分数为负。在所有实验中，我们将 Cfg 中的搜索深度设置为 25，这意味着 Pikafish 搜索 25 层。

## 3.2 象棋数据集构建

为了有效地训练和评估我们的模型，构建高质量且可靠的标准化数据集至关重要。我们从在线平台策划了一个大规模的公开开源象棋游戏语料库，其中包含数十万场 PGN 格式的比赛。每条记录都包含全面的元数据和两名玩家的详细移动序列，其中一个子集包含专家评论。原始的

![](images/27572bd88b925c35ee9f9a6a9e5d1f2c358bc8221c97a19118aa927f78a30a7c.jpg)  
图 2：我们提出的框架概述。第 1 阶段：使用板移动对数据的 SFT。第 2 阶段：SFT 以及包含分析的数据。第三阶段：构建细粒度的奖励函数，并与基于GRPO的强化学习方法相结合，进一步增强模型的空间策略推理能力。

使用开源 cchess 库解析 PGN 数据并将其转换为 FEN。此过程产生了 FEN-Move-Comment（可选）三元组形式的结构化数据集，其中每个实例代表特定的游戏状态、相应的移动以及（如果适用）专家注释。该管道系统地消除了不完整、低质量的条目，从而生成了一个对下游学习任务既具有代表性又稳健的精选数据集。

具体来说，我们只保留获胜方的棋步以及平局双方的棋步，不包括失败方的棋步。尽管获胜者的棋步可能包含错误，但这些错误通常会通过后续棋步进行纠正，从而获得胜利。相比之下，失败方的失误往往很严重，并直接导致失败。这种过滤确保了数据的有效性和质量。对于评论数据，我们过滤掉与游戏无关的评论，只保留那些与高质量动作相关的评论，高质量动作的定义是评估与最佳动作的差异小于阈值的动作 $\sigma _ { \mathrm { g o o d } }$ 。在所有实验中， $\sigma _ { \mathrm { g o o d } }$ 被设置为 100，代表评估系统中的狭窄边缘。为了确保数据隐私，我们使用 DeepSeek-V3 (DeepSeek-AI, 2024) 删除包含敏感信息（例如玩家姓名）的评论。选择标准如下：

$$
\_, \text { NewValue } = \text { Pikafish } (\text { Cfg }, \text { FEN } + \text { Move }),\tag{2}
$$

$$
\left| \text { NewValue } - \text { BestValue } \right| \leq \sigma_ {\text { good }}.\tag{3}
$$

数据预处理后，我们将数据集分为三个训练阶段和一个单独的测试集。

第 1 阶段包括 510 万个棋局对，而第 2 阶段和第 3 阶段分别包含 52.9K 和 52.8K 带人工注释的注释样本。该测试集包含 2,800 个高质量样本，涵盖专家级游戏的不同阶段。对于第3阶段和测试集，我们枚举了给定FEN下所有可能的合法动作，并计算相同设置下每个动作的评估分数以方便评估。

为了促进监督学习，我们根据 Pikafish 引擎提供的评估分数对游戏位置进行分类。具体来说，我们定义五类标签方案如下：

$$
\text { Situation } = \left\{ \begin{array}{l l} \text { Balanced }, & | \text { Value } | \leq \sigma_ {s} \\ \text { Slight   Adv.   (R / B) }, & \sigma_ {s} <   | \text { Value } | <   \sigma_ {l} \\ \text { Clear   Adv.   (R / B) }, & | \text { Value } | \geq \sigma_ {l} \end{array} . \right.\tag{4}
$$

这里，Value表示评估分数，其中正值有利于红色，负值有利于黑色。基于Pikafish的游戏分析惯例，我们设置 $\sigma _ { \mathrm { s } } = 1 0 0$ 和 $\sigma _ { \mathrm { l } } = 8 0 0$ 区分平衡、稍微有利和显著有利的位置。为了提高鲁棒性并降低对阈值调整的敏感性，我们还通过将轻微且明显的优势类别合并到单个“优势”类别中来引入简化的三类设置。

## 3.3 第一阶段和第二阶段：SFT on Board-移动和分析数据

为了使模型具备初步推理能力，我们使用收集的数据集对其进行微调。

然而，只有大约 1% 的数据包含人工撰写的评论，这限制了对战略理解的直接监督。为了有效地利用这个有限的带注释的子集，我们采用了两阶段微调策略。在第一阶段，我们对棋盘-走法对执行 SFT，使模型能够以文本格式解释棋盘状态并生成合理的走棋建议。在此基础上，第二阶段使用解说数据进一步微调模型，使其具备分析和评估比赛情况的初步能力。这种分层训练过程有助于初步增强模型在复杂游戏场景中的空间策略推理能力。

## 3.4 第三阶段：专家指导的基于 GRPO 的 RL 和奖励设计

为了进一步增强模型的空间策略推理和泛化能力，我们将这种复杂的能力分解为三个有针对性的奖励目标： $R _ { \mathrm { m o v e } } .$ 鼓励准确的着法生成； $R _ { \mathrm { a n a l y s i s } } ,$ 促进有效的位置分析；和 $R _ { \mathrm { f o r m a t } }$ ，增强模型推理格式的一致性和稳定性。这种模块化的奖励设计可以实现更可解释的学习信号，并促进每个子技能的有针对性的改进。

移动奖励 $( R _ { \mathrm { m o v e } } )$ 。为了增强模型的着法生成能力，我们引入了多级移动奖励函数 $R _ { \mathrm { m o v e } }$ 它从三个级别评估生成的移动的质量：合法、良好和最佳。具体来说，我们定义以下指标变量来捕获这些标准： $r _ { \mathrm { b e s t } } ~ = ~ \mathbb { I } ( \mathrm { M o v e } ~ = ~ \mathrm { B e s t M o v e } )$ $r _ { \mathrm { g o o d } } =$ I(移动=GoodMove), $r _ { \mathrm { l e g a l } } = \mathbb { I } ( \mathbf { M o v e }$ 有效）。所有判断均使用专业引擎Pikafish进行。因此，着法生成的最终奖励计算如下：

$$
R _ {\mathrm{move}} = r _ {\mathrm{legal}} + r _ {\mathrm{good}} + r _ {\mathrm{best}}.\tag{5}
$$

GoodMove 的定义是根据式（1）推导出来的。 3. 这样的奖励函数为模型分配更高的奖励以产生更高质量的着法建议，而无效的移动则获得零奖励。值得注意的是，我们事先使用 Pikafish 为训练位置中所有可能的动作预先分配了分数，以便模型能够及时评估它们，而不受 Pikafish 思考时间的影响。

分析奖励 $( R _ { \mathrm { a n a l y s i s } } )$ 。为了促进对董事会形势的准确和富有洞察力的战略分析，我们引入了分析奖励 $R _ { \mathrm { a n a l y s i s } } ,$ 它评估模型对当前位置的分析是否与高质量引擎 Pikafish 提供的评估一致：

$$
R _ {\text { analysis }} = \left\{ \begin{array}{l l} 1, & \text { if   the   analysis   is   correct } \\ 0, & \text { otherwise } \end{array} \right..\tag{6}
$$

该奖励采用二元评分方案，根据模型是否正确执行态势分析任务来确定分数：正确判断获得1奖励，否则获得0奖励。

形式奖励 $( R _ { \mathrm { f o r m a t } } )$ 该模型被提示产生战略分析和最终答案。具体来说，分析必须完全包含在 <Think>...</Think> 标签，而最终答案必须完全出现在 <Answer>...</Answer> 标签。预计答案将包括董事会情况分析摘要和行动建议。同时，如果没有其他内容出现在 <Think> 和 <Answer> 块，这样的输出被认为是格式良好的并且符合预期的推理格式。

$$
R _ {\text { format }} = \left\{ \begin{array}{l l} 1, & \text { if   the   format   is   as   expected } \\ 0, & \text { otherwise } \end{array} \right..\tag{7}
$$

当模型输出格式错误时，奖励 $R _ { \mathrm { m o v e } }$ 和 $R _ { \mathrm { a n a l y s i s } }$ 无法正确分配，导致奖励为零。这种机制鼓励模型更快地收敛到所需的输出格式。

训练算法。如图2所示，我们使用Stage 2模型初始化我们的策略，并采用GRPO算法进行训练。该过程由如上所述精心设计的奖励函数引导。具体来说，GRPO 对每个状态的一组候选输出进行采样，并计算组相对优​​势以优化策略。同时，阶段2模型作为参考来计算更新后的策略与参考之间的Kullback-Leibler散度，充当正则化项以防止策略过度偏离原始分布。该训练框架有效地平衡了候选者之间的相对性能改进和与参考模型的整体一致性，确保优化过程中的有效性和稳定性。

## 4 实验

## 4.1 实验配置

数据集。象棋数据集分为三个训练阶段和一个测试阶段。第 1 阶段采用 board-move 格式，包含 510 万个样本。第 2 阶段使用棋盘分析移动格式，包含 52.9K 样本。第 3 阶段采用棋盘移动价值格式，其中计算所有合法着法的价值得分，总计 52.8K 个样本。测试集由 2.8K 个样本组成。数据集构建的详细信息在前面的部分中描述。

基线。如表所示。 1，我们的实验评估了几个最先进的法学硕士，特别是那些对中文有大力支持的法学硕士（以中文代表Board-Str）。我们将这些模型分为两类：直接答案模型和推理模型。评估的模型包括最新版本 Qwen (Team, 2024), DeepSeek (Guo et al., 2025; DeepSeek-AI, 2024)， 和 Doubao (Seed et al., 2025) 系列。我们的模型， Xiangqi-R1-7B, 是根据微调 Qwen-2.5-7B-Instruct.

超参数。所有实验均在 4 \* A6000 GPU。在训练阶段，我们采用了 DeepSpeed ZeRO-2 (Rasley et al., 2020; Rajbhandari et al., 2021) 和洛拉 (Hu et al., 2022) 以减少 GPU 内存消耗。我们使用TRL库来实现GRPO算法的训练。有关配置的详细信息，请参阅附录 A。

## 4.2 评估指标

我们评估模型在两项任务上的性能：着法建议和情况分析。对于着法建议任务，我们采用三个基于采样的指标来量化模型的有效性。具体来说，legal@k 测量 k 个样本内至少生成一个有效动作的概率。 good@k 评估是否至少有一个高质量的动作，如等式 1 所示。 3. best@k 捕获模型在 k 次尝试内产生最佳着法的可能性。对于情境分析任务，我们采用基于分类的指标来评估模型评估游戏情境的能力。 3-class@k 指标将每种情况分为三种战略结果之一：红色优势、平衡或黑色优势。为了进行更细粒度的分析，我们进一步引入了 5-class@k 指标，它区分了五个类别：红色显著优势、红色轻微优势、平衡、黑色轻微优势和黑色显著优势。值得注意的是，我们仅在模型产生有效的移动时评估态势分析，因为无效的移动表明缺乏基本的游戏理解，使得任何正确的评估都可能是偶然的。

## 4.5 进一步分析

我们的实验表明，件数显著影响模型性能。我们在 5-32 个部件的 2,800 个测试位置上评估该模型。图 3 报告了这些范围内三个关键指标的前 1 分数。 legal@1 指标始终保持较高水平（约 0.95）且方差最小，表明该模型几乎总是生成合法的移动。然而，best@1 性能在中等棋子数中显著下降，大致对应于中局，可能是由于复杂性和战略需求的增加。 Good@1 中也出现了类似的趋势，性能在 19 到 28 件之间显著下降。所有三个指标都在高件数时达到峰值，这是开局的典型特征。

相比之下，这两个情况分析指标都随着件数的减少而稳步下降。我们将其归因于评估后期比赛位置的难度不断增加，其中较小的错误幅度使每个决定更加重要。即便如此，该模型在开局阶段表现强劲，游戏更加结构化和可预测。

强化学习提高了模型在件数上的性能，在态势分析方面取得了显著的进步。我们比较了我们的模型 Xiangqi-R1 使用 SFT-Stage2 模型在游戏的不同阶段进行比较，如图 4 所示。我们的研究结果表明 Xiangqi-R1 在各个游戏阶段的几乎所有指标上都优于 SFT-Stage2 模型。具体来说，legal@1 和 good@1 指标在每个阶段都表现出接近 10% 的收益，证明了我们方法的有效性。相比之下，best@1 指标在游戏中期阶段的改善更为有限，约为 5%。如前所述，此阶段游戏状态的复杂度最高，这对 7B 模型来说具有挑战性。我们相信，增加模型大小可以进一步提高复杂阶段的推理性能。

值得注意的是，与形势分析相关的指标显示出 15%–30% 的收益，强调了该模型在职位评估方面的强大潜力，并通过我们的奖励设计有效增强。然而，值得注意的是，开放阶段所有指标的改进相对较小，主要是因为 SFT-Stage2 模型在此阶段已经表现良好。

Xiangqi-R1 对高使用率进攻性棋子的熟练程度明显高于对受规则约束的防御性棋子的熟练程度。我们根据成功率和使用频率系统地评估法学硕士在执行各种象棋棋子的动作命令方面的表现。该模型在具有简单移动规则的常用棋子（例如兵和车）上表现良好，但对于具有更严格或更多上下文相关规则的棋子（包括国王和大象），其成功率会下降。

特别是，King 的成功率最低（0.859）。虽然其动作看似简单，但避免与对方国王直接对抗、受制时的限制等严格限制，需要对棋盘状态的准确认识，而错误解释这些规则往往会导致错误。这强调了任务的复杂性。尽管如此，我们的方法极大地提高了性能，在所有工件类型上实现了 95% 以上的总体成功率。

## 5 结论

在本文中，我们介绍 Xiangqi-R1，一个为中国象棋空间策略推理量身定制的 7B 参数模型。我们的多阶段训练框架集成了大规模专家注释数据、引擎评估以及基于 GRPO 的强化学习和多维度奖励。实验表明 Xiangqi-R1 显著优于更大的通用

搬迁合法性和战略分析法学硕士。这项工作为推进复杂空间领域的战略情报奠定了坚实的基础。

## 6 局限性

由于计算资源的限制，我们的实验仅限于 7B 参数模型。我们只采用基于文本的法学硕士，目前无法处理视觉板输入。在完整对局实验中，我们观察到我们的模型和通用 LLM 都无法可靠地完成整个游戏，这凸显了任务的内在难度和当前模型的局限性。尽管如此，我们的方法为该领域提供了一个有希望的方向。未来的工作将集中于改进残局推理、融入视觉输入以及增强全游戏玩法能力。

## C数据采集

高效训练和评估 Xiangqi-R1，我们构建了一个高质量、标准化的象棋数据集。鉴于数据规模庞大，我们计划以适当的方式公开发布匿名数据集。该数据集主要来源于几个可公开访问的专业象棋比赛记录平台，这些平台提供了高水平棋手的大量比赛日志。下面，我们描述了数据收集、清理、转换和过滤过程中采用的关键策略和程序。

## C.1 数据源和初始过滤

我们总共收集了 182,342 条游戏记录，全部采用象棋便携式游戏符号 (PGN) 格式标准化。每条记录都包含完整的游戏过程、移动顺序、游戏结果，在某些情况下还包含专家评论和注释。为了确保数据完整性和可用性，我们排除了具有错误走法顺序、无法解析的走法或丢失结果标签（获胜、失败或平局）的记录。经过初步清理后，我们保留了高质量的 PGN 数据子集用于后续处理。

## C.2 数据结构转换

为了便于模型训练和引擎分析，原始PGN数据被统一转换为Forsyth-Edwards Notation（FEN）格式。每个动作都表示为一个三元组（FEN、Move、Comment）。此转换是使用开源工具 cchess 进行的，该工具自动解析动作并生成位置编码。在转换过程中，我们进行了以下结构化处理：

• 生成当前位置的FEN以及每回合相应的走法；

• 如果可用，则在“注释”字段中保留专家评论，否则将其留空；

• 将每条记录视为独立样本，以促进特定州的预测学习。

此外，我们只保留决胜局中获胜方的走棋，以及平局中双方的所有走棋。这种方法是基于这样的观察：虽然胜方的走法可能存在错误，但其整体走法逻辑趋于合理，并且错误往往会在后期得到纠正。相反，失败方的错误往往是决定性的。这种过滤导致 $\mathbf { 6 , 9 1 9 , 6 3 3 }$ 样品。

## C.3 数据处理和分区

为了保护用户和玩家的隐私，我们应用了法学硕士 DeepSeek-V3 通过自动检测和删除真实姓名、位置和事件详细信息等敏感信息来净化评论内容。

此外，我们排除了不包含任何象棋相关关键词的评论（例如“红”、“黑”、“车”、“骑士”、“炮”等）。仅保留与高质量动作相关的专家评论。我们将 GoodMove 定义为由 Pikafish 引擎（在我们的实验中设置为深度 25）计算出的评估值 NewValue 与给定参数下最佳着法评估 BestValue 的误差在 100 百分兵 之内，如公式 1 中形式化的那样。 3.

按照这些预处理步骤，我们将数据集分为三个训练阶段和一个独立的测试集。为了支持位置评估任务，我们使用 Pikafish 评估分数来标记第 2 阶段和第 3 阶段的位置。此外，我们通过将“轻微优势”和“明显优势”类别合并为统一的“优势”类别，构建了一个三级标记方案，如等式 1 所示。 4. 测试集由2,800个精心挑选的高质量样本组成，红黑面各有50个位置，样本数量在5到32之间。

最终的数据划分总结如下：

• 第一阶段：5,109,543（FEN，Move）样本用于基本移动预测训练；

• 第2 阶段：52,913 个（FEN、Move、Comment）带注释的样本，用于情况分析和决策；

• 第三阶段：52,800 个（FEN、Move、Comment、Score）带注释的样本，重点关注增强推理稳定性；

• 测试集：2,800 个高质量样本，涵盖开局、中局和残局阶段，用于模型评估。

值得注意的是，在第3阶段和测试集中，详尽列举了每个FEN位置的所有合法动作，并通过Pikafish计算了它们的评估分数，以方便后续的评估、分析和分类任务。
