# 大语言模型能否形成战略推理能力？从学习国际象棋获得的后训练启示

Dongyoon Hwang<sup>1,2∗</sup> Hojoon Lee<sup>1,2∗</sup> Jaegul Choo<sup>1</sup> Dongmin Park<sup>2†</sup> Jongho Park<sup>2,3†</sup> <sup>1</sup>KAIST AI <sup>2</sup>KRAFTON <sup>3</sup>加州大学伯克利分校 {godnpeter, joonleesky}@kaist.ac.kr

## 摘要

虽然大语言模型 (LLM) 的强化学习 (RL) 在数学推理方面已显示出前景，但使用 RL 的 LLM 的策略推理在很大程度上仍未得到探索。我们研究法学硕士是否可以通过国际象棋中的强化学习来发展战略推理能力。为此，我们利用国际象棋预训练的动作价值网络为 LLM 的输出着法质量提供稠密奖励，这可以看作是知识蒸馏的一种形式。我们的实验表明，基于蒸馏的稠密奖励通常优于稀疏二元奖励。然而，令人惊讶的是，所有模型都远低于专家水平。我们提供了国际象棋推理训练的 SFT 和 RL 消融，并找到证据表明这种限制源于预训练模型对国际象棋的内部理解的缺陷——仅靠 RL 可能无法完全克服这一缺陷。该代码可在 https://github.com/krafton-ai/Chess-R1.

## 1 简介

具有可验证奖励的强化学习（RLVR）在开发大语言模型（LLM）的数学推理能力方面表现出了强大的性能 (Guo et al., 2025; Li et al., 2025; Yu et al., 2025)。虽然这些成功凸显了法学硕士的逻辑思维能力，但情报的一个关键维度仍然很大程度上未被探索：战略推理——在多主体环境中规划、预测对手行动和做出决策的能力。除了静态环境中的逻辑推理之外，策略推理更符合游戏、谈判、市场竞争等现实场景 (Zhang et al., 2024; Park et al., 2025).

为了研究这一差距，我们转向国际象棋，这是一种战略游戏，需要深厚的战略推理能力，例如位置评估、长期规划和推理对手的意图。此外，国际象棋为法学硕士应用 RLVR 提供了有利的环境，因为它提供了丰富的公开可用的游戏记录和关于最佳动作的人工注释推理。考虑到这样一个检验策略推理的测试平台，我们提出以下研究问题：

## 法学硕士可以通过 RLVR 和国际象棋来培养战略推理能力吗？

为此，我们训练 Qwen2.5 (Qwen: et al., 2025) 和 Llama3.1 (Grattafiori et al., 2024) 使用 GRPO 预测国际象棋下一个最佳走法的模型 (Shao et al., 2024)。与依赖于稀疏二元奖励（正确/不正确）的典型 RLVR 方法不同，国际象棋允许密集的奖励信号：我们利用这样一个事实，即我们可以根据估计的获胜概率来评估每个动作，提供与动作质量成比例的分级反馈。我们使用预先训练的国际象棋专家作为奖励模型（一种从 Q 值网络到 LLM 的知识蒸馏形式）来实现这一点，它评估位置强度并提供密集的连续奖励，而不是稀疏的二进制奖励。

我们对国际象棋谜题数据集进行了系统实验，并观察到以下内容：

• 在国际象棋谜题准确性方面，基于蒸馏的稠密奖励大大优于稀疏二元奖励。

• RL 微调的性能比监督微调（SFT）更强；然而，其性能稳定在 25-30% 的拼图准确度上，远低于人类专家的表现 (60-80%)。

• 额外的推理蒸馏显示没有 RLVR 增益，这表明尽管进行了进一步的训练后，模型仍无法开发有意义的策略推理。

通过额外的失败分析，我们发现基础法学硕士通常很难掌握基本的国际象棋规则。因此，我们假设，与数学领域的逻辑推理相比，国际象棋中战略推理的出现有限可能源于法学硕士预训练期间对国际象棋特定知识的接触不足。我们的实证研究结果也支持最近的说法，即强化学习主要增强了预训练法学硕士的现有能力 (Li et al., 2025; Zhao et al., 2025b)，并为旨在在新环境中激发推理能力的从业者提供见解：预先训练的领域知识对于开发高级推理至关重要。

## 2 国际象棋法学硕士训练后

## 2.1 国际象棋数据集

训练数据。我们使用从 Lichess 谜题数据库收集的 Lichess 谜题<sup>1</sup> 作为我们的训练数据集。每个谜题都包含一个初始棋盘局面以及一系列连续的动作，当按顺序玩时，会带来战术上的胜利。为了创建训练数据集，我们将每个谜题的解决轨迹分解为单独的位置-动作对。形式上，每个谜题都表示为一条轨迹 $\bar { g } ^ { ( i ) } = ( s _ { 0 } ^ { ( i ) } , a _ { 0 } ^ { * ( i ) } , s _ { 1 } ^ { ( i ) } , a _ { 1 } ^ { * ( i ) } , \ldots , s _ { T _ { i } } ^ { ( i ) } ) .$ 在哪里 $i \in \{ 1 , \ldots , N \}$ 索引第 i 个谜题， $s _ { t } ^ { ( i ) }$ 是时间步的棋盘局面 $t , a _ { t } ^ { * ( i ) }$ 是最优着法，T<sub>i</sub> 是轨迹长度。我们通过聚合所有这些对来构建位置多样化的训练数据集： $\mathcal { D } = \{ ( s _ { t } ^ { ( i ) } , a _ { t } ^ { * ( i ) } ) ~ | ~ i \in \{ 1 , \dots , N \} , ~ 0 \leq t < T _ { i } \} .$ 数据集 D 总共有 19.2k 个训练样本。

提示模板。我们需要一个文本界面，法学硕士可以通过该界面推断国际象棋的位置。基于我们收集的国际象棋数据集 D，我们采用使用 Forsyth–Edwards Notation (FEN) 的简洁提示格式 (Edwards, 1994) 棋盘状态的格式和移动的标准代数表示法 (SAN) 格式。国际象棋数据的替代表示形式，例如便携式游戏符号（PGN）或通用国际象棋接口（UCI）移动符号中的完整移动历史记录，并没有产生可测量的改进。我们还要求模型将推理放入 <think> 标签和答案在 <answer> 标签 (Guo et al., 2025; Zhao et al., 2025a)。有关提示格式的定性示例和消融研究，请参阅附录 A、C.1。

## 2.2 强化学习微调

为了用国际象棋强化学习训练法学硕士，我们采用 GRPO (Shao et al., 2024) 策略改进，最近通过对比同一提示的多次采样轨迹被证明是有效的 (Guo et al., 2025)。具体来说，我们采用两种替代奖励计划：

• 稀疏奖励：二元指标是否预测移动 $\hat { a } _ { t }$ 匹配最佳答案 $a _ { t } ^ { \star }$

$$
r _ {\text { sparse }} = \mathbf {1} \big [ \hat {a} _ {t} = a _ {t} ^ {\star} \big ].
$$

• 稠密奖励：由预先训练的动作价值网络提供的密集实值分数 $Q _ { \theta } ( s , a )$ 来自 Ruoss 等人。 (2024) 预测移动后获胜概率：

$$
r _ {\mathrm{dense}} = Q _ {\theta} (s _ {t}, a _ {t}), \qquad Q _ {\theta} (s, a) \in [ 0, 1 ].
$$

批评家 $Q _ { \theta } ( s , a )$ 是一个 270 M 参数、16 层解码器专用 Transformer (Vaswani et al., 2017) 在 15B 上训练 10 M 优化步骤 Stockfish 带 HL-高斯损失的带注释的状态-动作对 (Imani & White, 2018)。在 RL 微调期间查询该专家网络可以被视为知识蒸馏的一种形式 (Zhang et al., 2025c)：密集的胜率评估注入了老师的战略洞察力，不仅指导学生采取最佳行动，还指导学生采取次优行动。评论家本身获得了 2299 ELO，并且在 Lichess 谜题上达到了 95.4% 的准确率。

我们还包括两个辅助的二元奖励：(i) $r _ { \mathrm { f m t } } \in \{ 0 , 1 \}$ 为了正确的标签格式（<think> 用于推理和 <answer> 寻求答案），以及 $\mathbf { \Phi } ( \mathrm { i i } ) \mathbf  \dot { \} } r _ { \mathrm { l a n g } } \in \{ 0 , 1 \}$ 强制输出为英文。因此，第 t 步的总训练奖励为 $r _ { t } = \lambda _ { \mathrm { s p a r s e } } r _ { \mathrm { s p a r s e } } +$ $\lambda _ { \mathrm { d e n s e } } r _ { \mathrm { d e n s e } } + \lambda _ { \mathrm { f m t } } r _ { \mathrm { f m t } } + \lambda _ { \mathrm { l a n g } } r _ { \mathrm { l a n g } }$ 。我们设定 $( \lambda _ { \mathrm { s p a r s e } } = 1 , \lambda _ { \mathrm { d e n s e } } = 0 )$ 对于稀疏的奖励设置和 $( \lambda _ { \mathrm { s p a r s e } } = 0 , \lambda _ { \mathrm { d e n s e } } = \overset { \cdot } { 1 } )$ 对于密集的奖励设置。

## 3.2 推理SFT

为了探究 RL 平台期的原因，我们询问来自高级推理模型的特定领域推理轨迹是否可以使法学硕士更好地利用 RL 信号来获取国际象棋技能，并克服之前观察到的性能上限。为此，我们策划了一个由 OpenAI 生成的 1k 条高质量推理轨迹组成的推理 SFT 语料库 o3，包括候选行动评估、战术评估和战略论证（详情请参阅附录 B.2）。执行 SFT 后 Qwen2.5-7B 和 Llama3.1-8B 借助这个语料库，我们与专家评论家 Q 一起应用了 GRPO RL 流程<sub>θ</sub>(s,a) 反馈。

虽然法学硕士在推理 SFT 后产生了明显更全面的推理轨迹，但图 3 表明，令人失望的是，当随后使用 RL 进行训练时，它们表现出类似的谜题准确性平台。实际上， Llama3.1-8B相对于非 SFT 基线，其性能实际上有所下降。这些结果提出了一个问题：国际象棋表现停滞不前的原因是否不是推理能力不足，而是国际象棋知识不足。如果没有预训练中的广泛领域知识，仅靠强化学习可能无法提供战略游戏所需的特定于国际象棋的理解。

## 3.3 故障分析

为了研究 RLVR 对国际象棋的性能限制是否源于国际象棋领域知识的不足，我们评估了法学硕士的两项诊断任务，这些任务需要对国际象棋规则有基本、必要但重要的理解。

局态理解：给定一个 FEN 字符串和一到五个 SAN 移动的合法序列，该模型会预测 FEN 中的结果位置。该模型必须有一个忠实的国际象棋规则内部模拟器才能成功完成这项任务。

MATE 谜题：MATE 数据集中的每个实例 (Wang et al., 2024) 提供一个游戏中期位置以及两个候选动作。该模型必须通过战术评估来识别优势举措。

正如表 1 所总结的，所有测试的法学硕士在这两种诊断上都表现不佳，证实了国际象棋状态转换和策略的内部模型不充分。我们测试了 Base 和 Instruct 变体 - Instruct 模型具有更好的格式合规性，尽管它们与 Base 模型共享相同的基础知识。这一缺陷有力地支持了我们之前的假设：当前的模型缺乏对国际象棋的基本理解，导致它们无法仅通过奖励优化来发展高性能。

由于模型无法可靠地跟踪游戏状态或识别基本策略，因此奖励优化无法开发高质量的战略推理并引发专家级的游戏。

## 4 相关工作

RLVR 用于 LLM 推理。右室VR (Lambert et al., 2024) 已经成为一个强大的范式，可以为具有确定性评估标准的任务引发法学硕士推理。值得注意的是，在数学领域，简单的基于规则的奖励已被证明非常有效，而不需要复杂的奖励模型 (Guo et al., 2025; Yu et al., 2025; Wang et al., 2025)在 AIME 等数学奥林匹克竞赛中取得与人类相当甚至超越人类的成绩。此外，一些工作也将 RLVR 的应用扩展到其他领域 (Liu et al., 2025b; Zhang et al., 2025a; Gurung & Lapata, 2025).

尽管取得了这些成功，但有关 RLVR 成功的基本问题仍未得到充分探讨。最近的研究表明，它的成功往往源于基础模型中已有的丰富知识，而不是通过强化学习真正学习到的 (Liu et al., 2025a; Zhao et al., 2025b; Li et al., 2025; Shao et al., 2025; Yue et al., 2025)。为了充分了解 LLM 的能力及其通过 RL 开发真正推理能力的局限性，仍然有必要对模型、任务、强化学习算法和规模进行系统研究。

国际象棋法学硕士。最近的工作探讨了法学硕士如何解决国际象棋任务，补充传统的国际象棋引擎。虽然像 AlphaZero 这样的专业网络 (Silver et al., 2017) 通过自我对弈和搜索实现超人的表现，但它们缺乏人类可读的洞察力。相反，法学硕士可以用自然语言解释动作，但往往缺乏精确的战略理解，导致幻觉或非法动作。为了弥补这一差距，研究人员将国际象棋引擎与法学硕士集成起来，以提供流畅的棋步解说 (Kim et al., 2025) 并开发了以国际象棋为中心的模型，例如 ChessGPT (Feng et al., 2023) 通过特定领域的预训练。根据 MA​​TE 数据集的专家原理进行微调 (Wang et al., 2024) 使 Llama 超越的模型 GPT-4 和克劳德在二元移动选择。最值得注意的是，ChessLLM (Zhang et al., 2025b) 证明在完整对局的 20B 代币上进行微调的 LLM 可以在专家级别下棋，无需外部搜索即可达到 1788 的 Elo；然而，以 FEN 为中心的训练存在过度拟合自然语言响应并将其退化为支离破碎的符号的风险。

尽管取得了这些进步，现有方法主要依赖于人类游戏或引擎指导的监督学习，而不是自主战略开发。法学硕士是否可以通过强化学习发展真正的国际象棋推理仍然很大程度上尚未被探索，特别是在了解这种学习是否产生可转移的战略洞察力或仅仅是模式记忆方面。我们的工作利用国际象棋作为研究法学硕士自主战略发展的受控测试平台来解决这一差距。

## 5 结论与局限性

我们研究了法学硕士是否可以通过国际象棋上的 RLVR 开发策略推理，引入了一种利用来自预训练的行动价值网络的稠密奖励的新颖方法。虽然稠密奖励通常优于稀疏奖励，但所有模型都远低于人类专家，揭示了当前训练后方法的根本局限性。令人惊讶的是，尽管在 OpenAI 的高级跟踪训练中产生了更结构化的推理 o3，当随后使用 RL 进行训练时，模型仍然会产生类似的性能平台。我们的失败分析揭示了一个潜在的根本原因：目前的法学硕士没有表现出足够的内部国际象棋知识。这些结果引发了人们的猜测：强化学习无法克服贫乏的领域知识。虽然强化学习擅长优化行为以获得奖励，但法学硕士在缺乏预训练时无法从头学习战略思维所需的基础知识。我们假设 RLVR 在数学领域的成功源于丰富的预训练暴露，这与国际象棋的覆盖范围极小不同。我们的研究结果与最近的研究结果一致，表明强化学习只会增强现有能力 (Li et al., 2025; Liu et al., 2025a; Yue et al., 2025)。对于新领域的战略推理，预训练期间足够的领域知识至关重要，而仅靠训练后的强化学习是不够的。

## B.1 Lichess 谜题数据集

训练数据收集。我们从 Lichess 谜题数据库中收集解算者评级从 200 到 2800 Elo 的 Lichess 谜题。每个谜题都包含一个初始棋盘局面和一系列导致战术胜利的动作。为了创建位置-动作训练对，我们分解每个谜题的解决轨迹，其中具有 T 个移动的谜题生成

T 个单独的训练样本。此分解过程为我们的数据集 D 生成了总共 19.2k 个训练样本。

评估协议。我们使用包含 10K 个 Lichess 谜题的评估数据集，通过解谜能力来评估对国际象棋的理解，这些谜题涵盖了不同的难度级别： (Ruoss et al., 2024)。我们的评估指标是谜题准确性，定义为模型的完整动作序列与真实解决方案序列完全匹配的谜题的百分比。这种严格的评估标准保证了模型不仅要识别好棋，还要完整、正确地解决难题，从而对国际象棋推理能力进行全面评估。为了确保一致性，我们在评估期间使用与训练时相同的提示模板。

## C 消融研究

我们在实验中提供了各种消融，以确保我们的实验不仅仅局限于我们特定的提示格式或奖励设计。

## C.1 提示格式化

我们对不同的提示格式进行了系统实验，同时以专家评论家奖励作为默认奖励配置执行强化学习，检查两个关键设计轴：(i) 移动动作表示和 (ii) 棋盘状态表示。此外，我们调查了在提示中明确提供合法动作的必要性，这被证明是有意义学习的关键要求。对于移动动作表示，我们测试了 UCI 和 SAN 表示法。对于董事会状态表示，我们取消了 FEN 和 PGN 格式。

合法着法要求：为了调查提供合法着法的必要性，我们使用带有 SAN 移动符号的基线 FEN 棋盘表示进行了实验，比较了有和没有明确合法着法信息的性能。如图 6 所示，我们发现，当提示中未明确提供合法举措时，法学硕士无法学到任何有意义的内容。这一发现是法学硕士缺乏大量内部国际象棋领域专业知识的额外证据。如果没有关于可能和不可能的行动的明确信息，模型就无法取得有意义的进展。

## C.2 稠密奖励

当我们的专家评论家网络提供稠密奖励时 $Q _ { \theta } ( s , a )$ ，我们探索了两种从模型的胜率预测中提取奖励信号的方法：直接胜率反馈和标准化排名反馈。

直接胜率反馈。如方程（2.2）所述，我们直接使用专家评论家的预测胜率作为奖励信号。例如，如果批评者预测给定位置的特定移动有 67% 的获胜概率，我们提供 $r _ { \mathrm { d e n s e } } = \mathbf { \hat { 0 } } . 6 7$ 作为奖励。

标准化排名反馈。或者，我们可以将胜率预测转换为相对排名。鉴于一系列法律举措 $\big \{ a _ { 1 } , a _ { 2 } , \dots , a _ { L } \big \}$ 在状态 $s ,$ 我们首先获得胜率预测 $\left\{ Q _ { \theta } ( s , a _ { 1 } ) , Q _ { \theta } ( s , a _ { 2 } ) , . . . , Q _ { \theta } ( s , \dot { a } _ { L } ) \right\}$ ，然后根据预测的胜率对这些动作进行排名。标准化排名奖励定义为：

$$
r _ {\mathrm{dense}} = \frac {\operatorname{rank} (a _ {t}) - 1}{L - 1} \in [ 0, 1 ]\tag{1}
$$

排名在哪里 $\left( a _ { t } \right)$ 表示所选操作的排名 $a _ { t }$ （等级1为最高胜率，等级L为最低胜率），L为合法步数。

![](images/798bab1a64137d078ce44864e959b778cdbae980e7d548243bd1aa190342e834.jpg)  
图 9：直接胜率反馈和归一化排名反馈作为稠密奖励的评估绩效比较 Qwen2.5-7B 和 Llama3.1-8B.

我们在模型变体中比较了这两种方法，发现不同的学习动态具有相似的最终结果（图 9）。为了 Qwen2.5-7B，标准化排名反馈最初加速了学习，但最终达到了与直接胜率反馈相似的性能。为了 Llama3.1-8B，胜率反馈在整个训练过程中表现出始终如一的卓越表现。尽管学习轨迹不同，但这两种方法在两个模型中都收敛到相似的最终表现，这表明虽然学习动态不同，但绝对胜率信息和相对排名的最终有效性对于学习国际象棋来说是相当的。然而，在模型和奖励公式中观察到的独特学习动态揭示了有趣的依赖于模型的敏感性，值得进一步研究。了解为什么不同的模型对不同的反馈机制有不同的反应可以为开发更有效的训练程序提供信息，从而有可能提高国际象棋和其他战略领域的表现，为未来的工作提供一个令人兴奋的方向。
