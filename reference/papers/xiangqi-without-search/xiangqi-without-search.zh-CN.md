## ABSTRACT

我们开发了一种高性能的中国象棋人工智能，其运行不依赖搜索算法。该人工智能已经展现出与前 0.1% 人类玩家相当的竞争能力。通过消除通常与此类系统相关的搜索过程，该人工智能实现的每秒查询数 (QPS) 率超过基于蒙特卡罗树搜索 (MCTS) 算法的系统千倍以上，并且超过基于 AlphaBeta 剪枝算法的系统千倍以上。 AI训练系统由监督学习和强化学习两部分组成。监督学习提供了一个初步的类人的中国象棋AI，而基于监督学习的强化学习则将整个AI的实力提升到了一个新的水平。基于这个训练系统，我们进行了足够的消融实验，发现： 1.相同参数量的Transformer架构在中国象棋上比CNN有更高的性能； 2.双方可能的动作作为特征，可以大大改善训练过程； 3. 选择性对手池，与纯粹的自我对战训练相比，会带来更快的进步曲线和更高的力量极限。 4. Value Estimation with Cutoff(VECT)改进了原有PPO算法的训练过程，我们将给出解释。

## 引言

深度强化学习 (RL) 在开发能够掌握各种任务（从玩 Atari 游戏到解决复杂的现实问题）的自主代理方面取得了显著的成功<sup>1–9</sup>,.特别是，它在棋盘游戏中的应用已经带来了里程碑，例如 DeepMind 的 AlphaGo 和 AlphaZero<sup>10,</sup> <sup>11</sup>在围棋比赛中击败人类冠军的 ，以及在即时战略游戏《星际争霸 II》中取得特级大师地位的 AlphaStar<sup>12</sup>。这些成就凸显了强化学习处理复杂战略决策的潜力。

中国象棋，又称象棋，是一种两人对弈的策略棋盘游戏，与国际象棋游戏有相似之处。它是中国最受欢迎的棋盘游戏之一，已有数百年历史，以其复杂性和战略深度而受到爱好者和学者的推崇。标准象棋棋盘是一个 10x9 的方格，有一个显著的特征——河——它划分了对立的两个阵营并影响棋子的移动。

每个玩家一开始都有一套 16 个棋子：一名将军（国王）、两名顾问、两头大象、两辆战车、两门大炮、两匹马和五名士兵。上述棋子都有独特的移动规则，例如大象无法过河，大炮需要“屏幕”棋子才能捕获。胜利是通过将死或压制对手的将军来实现的。

中国象棋需要一系列动态的战术和更深层次的策略，强调进攻和防守的平衡以及进攻时机的细致。该游戏呈现了一个天文数字般巨大的状态空间，估计约为 10<sup>50</sup> 可能的游戏位置。这种巨大的规模给人工智能带来了相当大的挑战，特别是对于容易出现组合爆炸的确定性搜索算法。

传统的中国象棋人工智能方法强调使用 alpha-beta 剪枝和其他启发式搜索方法，虽然有效，但受到检查广泛博弈树所需的计算资源的限制。此外，这些算法需要手工设计的评估函数来封装人类对游戏的理解，这可能是僵化的并且无法适应新的情况。

与这些搜索方法相比，强化学习 (RL) 代理（例如在最近成功的 AlphaGo 和 AlphaZero 中应用的代理）已经证明了从游戏体验中学习和适应的潜力，并且只需最少的人工启发式方法。然而，将这些方法应用于中国象棋人工智能面临两个主要挑战：一是以保留丰富上下文的方式对游戏状态进行有效编码，并使神经网络能够有效地评估棋局位置；二是如何对棋局进行有效编码。另一个是制定一种强化学习算法，该算法可以在没有启发式搜索的明确指导的情况下深入了解游戏的广阔战略深度。

基于蒙特卡罗树搜索（MCTS）的算法<sup>13–15</sup>，例如 AlphaGo 或 KataGo<sup>16</sup>，通常需要大量模拟来计算下一步行动。例如，KataGo 模拟了 800 次，需要神经网络至少进行 800 次前向推理。众所周知，涉及神经网络的计算是高度资源密集型的。因此，基于MCTS的搜索算法在许多现实场景中的应用并不实用。我们的主要贡献是尝试从棋盘游戏AI的生产过程中消除MCTS这种资源密集型算法的使用。通过优化算法过程中的其他模块，我们的目标是开发一种棋盘游戏人工智能，可以在不依赖 MCTS 的情况下与顶级人类玩家水平竞争。

## 方法

## 训练算法

我们的中国象棋人工智能的开发围绕着强大的训练算法，解决与游戏复杂的动作空间和战略深度相关的挑战。该算法分为两个主要阶段，如图（1）所示： 1.带有辅助任务的监督学习； 2. 使用具有不同策略的对手池进行强化学习。

## 带辅助任务的监督学习

在初始阶段，我们利用人类专家对局的大型数据集向人工智能灌输中国象棋的基本能力水平。基于精心设计的采样曲线，我们从收集的游戏数据中进行采样，获得游戏状态作为神经网络的输入。对于每个游戏状态，都有一个相关的走法选择，这可能是顶级人类玩家根据当前情况选择的走法，也可能是我们使用 alpha-beta 剪枝算法计算得出的走法。为了更有效地处理广阔的动作空间（90x90），我们将其分解为两个步骤。第一个是选择棋盘上的一个棋子（最多 16 个选择，但如果某些棋子被吃掉，则数量会减少），第二个是为该棋子选择有效的走法（最多 90 个选择，但根据游戏规则和当前棋盘状态，通常会更少）。

样本曲线在中国象棋游戏中，样本分布极不平衡。具体来说，整个游戏过程可以分为以下三个阶段：开局、中局、残局。开局是指从比赛开始到双方基本形成初始阵型的阶段。这一阶段的主要目标是合理排列棋子并快速发展，特别是车、马、炮等攻防关键棋子。在这个阶段，协调和保护棋子、避免早期失误导致吃掉重要棋子、建立稳固的防守、寻找对手防守的漏洞至关重要。中局是指双方基本完成开局准备，开始进攻、防守、交换棋子等各种战术动作的阶段。这一阶段的特点通常是战斗激烈、局势变化频繁。残局是指棋盘上棋子较少，双方争夺最后胜利的阶段。这个阶段通常需要高计算能力和精确的判断。因此，随着游戏的进行，对计算精度的要求越来越高。因此，我们设计了以下采样函数：

$$
p \sim \log (a * t + b) + c
$$

其中 t 是游戏步骤。

辅助任务我们设计辅助任务来改进训练过程。辅助任务旨在预测给定动作后的胜率。通过预测行动的结果，人工智能不仅可以考虑即时策略，还可以考虑长期战略影响。考虑到不同的棋子具有独特的移动能力并对游戏产生不同程度的影响，这一点特别有用。因此，人工智能不仅学习评估特定动作，而且还了解决定棋子价值和位置优势的基本原则。此外，经过良好学习的获胜率预测器可以用作强化学习的初始值函数。

规则特征 中国象棋，也称为象棋，是一种复杂的棋盘游戏，通常需要大量的计算模拟来确保每一步棋都是最佳的。此要求与蒙特卡罗树搜索 (MCTS) 算法的功能密切相关。在我们的研究中，我们将中国象棋的规则嵌入到特征空间中，以增强人工智能对游戏的理解。

对于神经网络的输入，我们不仅包括当前棋盘状态，还包括另外两类通道： 1. 根据当前位置，识别哪些棋子可以移动以及可以移动到哪些位置。 2. 从对手的角度出发，根据当前位置，确定潜在的行动及其目的地。

我们随后的分析清楚地表明，这些功能显著加快了基于 ResNet 架构的网络的训练过程，并且有助于显著提高整体性能。

## 强化学习

在监督学习阶段之后，我们努力通过引入强化学习（RL）来进一步提高人工智能的性能和适应性，强化学习通常由马尔可夫决策过程（MDP）来描述。代理可以采取一些行动 $a _ { t }$ 根据状态在时间 t $s _ { t } ,$ ，然后环境将转移到下一个状态 $s _ { t + 1 }$ 并给予奖励 $r _ { t }$ 对于代理，服从动态 $P ( s ^ { \prime } , r ^ { \prime } | s , a )$ 。 RL 的目标是最大化沿轨迹累积的奖励，

$$
\max \sum_ {n} \gamma^ {n} r _ {t + n}
$$

在哪里 $\gamma \mathrm { i s }$ 保证算法收敛性的折扣因子。我们使用近端策略优化（PPO）算法<sup>2</sup>，考虑到其在平衡勘探和开采方面的优势。然而，PPO 的标准应用程序进行了修改，以适应中国象棋的确定性和高风险性质。为了应对中国象棋背景下 PPO 的挑战，我们进行了以下调整：

开局策略多样化 在中国象棋的开局阶段，有多种不同的起手玩法，从防守到进攻，再到更平衡的方法。顶级人工智能系统需要熟练地处理这些不同的风格。为了防止AI在自我对弈过程中陷入次优状态，我们设计了一个名为“开放策略多样化”的概念。这种方法确保人工智能探索广泛的战略可能性，从而增强其在真实游戏场景中的适应性和鲁棒性。我们不是从策略分布中抽样，而是手动策划一组来自顶级人类玩家的开局动作。开局书中的这种多样化确保了我们的人工智能能够接触到各种游戏开始，从而鼓励从游戏一开始就有更广泛的战略理解。

动态对手池众所周知，在强化学习中采用自我对弈作为训练方法很容易导致循环陷阱，模型A击败模型B，模型B击败模型C，模型C击败模型

答：因此，我们从 AlphaStar 中使用的“联盟”概念中汲取了灵感，并设计了多种对手模型，在自我对战过程中充当对手。该池根据性能指标和风格评估不断更新，确保我们的主要人工智能模型定期受到各种战略类型的挑战。该池的动态性质促进了强有力且多功能的策略的出现，能够抵消不同的策略。

对于每场比赛，根据当前训练模型对对手模型的胜率，选择池中的对手模型 i 之一 $r _ { i } .$ 。对手强的模型（胜率较低）更有可能被选择。采样方法的表达式如下：

$$
p _ {s e l e c t e d} ^ {i} \propto e ^ {- r _ {i} / \tau}
$$

对手模型池使用监督学习中恢复的模型进行初始化。当当前训练模型对池中模型的最低胜率超过阈值时，将被添加到对手模型池中。此外，为了更好地挑战训练模型，提高了对手模型的采样温度（更像ArgMax），而训练模型的温度保持不变。

Value Estimation with Cutoff 对于 PPO 训练，人们通常使用 GAE（General Advantage Estimation）来估计优势函数<sup>17</sup>:

$$
\hat {A} _ {t} ^ {G A E} = \sum_ {n = 0} ^ {+ \infty} (\gamma \lambda) ^ {n} \delta_ {t + n} ^ {V}
$$

在哪里 $\delta _ { t } ^ { V } = r _ { t } + \gamma V ( s _ { t + 1 } ) - V ( s _ { t } )$

经过分析，我们发现了在类似国际象棋的对抗游戏中使用 PPO 算法所特有的挑战，特别是在价值函数的估计方面。首先，PPO 是一种同策略算法，也利用熵损失来平衡探索和利用。因此，它不可避免地会在游戏过程中采样异常好的或异常差的动作。这种可变性会导致胜率从 0% 到 100% 剧烈波动，反之亦然，导致价值函数大幅波动，增加神经网络的拟合难度。而且，随着游戏的进行和采样步数的增加，这种现象变得更加明显。由此可见，有必要在轨迹处理中实现截断，这称为带截止值估计（VECT）。

VECT的核心算法是：

$$
\hat {A} _ {t} ^ {V E C T} = \sum_ {n = 0} ^ {L} (\gamma \lambda) ^ {n} \delta_ {t + n} ^ {V}
$$

上述训练算法的调整旨在培养人工智能不仅能够掌握中国象棋的客观细微差别，而且能够实现高水平的游戏创造力和适应性。通过这些创新的算法增强功能，我们的目标是提高人工智能的熟练程度，使其能够在没有 MCTS 等传统的计算要求较高的搜索算法的情况下，以与顶级人类玩家无法区分的水平进行竞争。

## 训练数据

在我们的研究过程中，我们从 LightSpeed 和 Quantum Studio 的“天天象棋”平台收集了大量数据集。值得注意的是，在数据收集阶段，我们采取了谨慎的措施来过滤掉玩家的个人信息和游戏详细信息等私人数据。仅保留国际象棋比赛记录，并以符合国际标准的便携式游戏符号（PGN）格式存储。

数据收集以两种不同的方法进行。第一种方法涉及从前 10% 的玩家收集数据，封装大约 500 万条记录。对于每个游戏场景，这些精英玩家所选择的动作都有专门的记录。第二种方法扩大了范围，涵盖了更广泛的人类专业知识，从初学者到顶级玩家，涵盖了千万个游戏场景。在这种方法中，使用 Alpha-Beta 剪枝算法创建的代理对动作进行了注释，以增强模型训练的通用性。

此外，为保证数据的完整性和相关性，数据清洗采用以下规则： 1、剔除局数小于10局的比赛记录。 2. 删除了由于网络问题导致玩家掉线而终止的游戏。

## 模型架构

从概念上讲，我们的模型映射了观察结果 $\mathbf { 0 } _ { t }$ 使用神经网络骨干 f 执行动作 a $f _ { \theta } .$

观察结果 $\mathbf { 0 } _ { t }$ 是一个张量（大小 $H * W * ( 2 * C ) )$ ，包括董事会信息（大小 $H * W * C )$ 和（大小的有效移动信息 $H * W * C )$ $H = 1 0$ 和 $W = 9$ 是板的高度和宽度， $C = 7$ 表示棋类型的编号。有关棋盘信息，棋盘<sub>ij</sub> 是国际象棋第 i 行第 j 列的 one-hot 表示。对于有效的移动信息， $\nu a l i d m o \nu e _ { i j k }$ 是一个标志，指示第 i 行第 j 列是否可以被类型 k 的国际象棋一步访问。

动作 a 是 N = 8100 个可能的移动的单热表示（每个移动可以由一对表示） < start, end >，开始和结束最多有 90 个选择）。无效的动作在训练和测试中都会被掩盖。

至于神经网络主干 $f _ { \theta } ^ { \mathrm { ~ ~ } }$ ，基于 CNN 和基于 Transformer 的架构都在这项工作中得到了验证<sup>18–20</sup>.

对于基于 CNN 的神经网络，我们采用流行的 ResNet 作为主干<sup>21</sup>。上面提到的观察结果可以被视为图像并无缝馈送到 ResNet。考虑到国际象棋的场景，我们通过修改入口处理块推导了原始ResNet的变体（在下面的论文中用mod-ResNet表示）。具体来说，将 conv1 从 conv(7x7, 64, 2) 更改为 conv(1x1, 64, 1)，并删除最大池。修改背后的见解是与经典图像分类任务相比，国际象棋背景下每个“像素”的重要性和必要性。实验结果表明，该修改带来了强度的显著提高。

对于基于 Transformer 的，我们利用 ViT，它是一种基于 Transformer 的分类架构<sup>22</sup>。出于 mod-ResNet 中的类似动机，我们将观察的每个“像素”视为一个标记，而不是默认修补相邻的“像素”。从 mod-ResNet 到 ViT 的过渡实现了强度的巨大提高。我们将这种提升归因于 Transformer 强大的空间关系理解能力。

## 消融研究

## 样本曲线

中国象棋的样本分布明显不平衡，不同阶段的走法风格存在显著差异。因此，对训练样本执行必要的采样程序至关重要。针对这个问题，我们设计了具体的采样曲线：

$$
p \sim \log (\frac {t}{2 T} + e ^ {- 1}) + 1. 5
$$

其中T是一场游戏的总时长，彼此不同，t是游戏的当前步骤。这条曲线说明，随着游戏的进行，每一步的选择都需要越来越高的精度。如图（2）所示，我们使用modResNet18模型进行了消融研究，比较了训练过程中该采样曲线与均匀采样的效果。我们观察到整体预测准确性，特别是在游戏中期和最后阶段，得到了提高。

## 特征与规则

在本次讨论中，我们探索中国象棋的有效特征建模。如果采用搜索技术，特征建模的重要性可能会降低，因为智能体可以不断向下模拟，最终实现对当前情况的全面了解。然而，在缺乏搜索和模拟的情况下，需要代理对整个棋盘和游戏规则有更深入的了解。为此，我们考虑了以下三种特征建模方法：

• 特征仅由棋盘上棋子的信息组成。

• 包括棋盘状态和玩家可用的各种移动选项的功能。

• 包含棋盘信息以及双方玩家基于当前情况的所有可能行动的功能。

我们在图中展示了这三种建模方法的训练曲线，其中横轴代表训练时间，纵轴显示相对于基线的胜率和平局率，如图（3）所示。从这些训练曲线中，我们观察到以下有趣的现象：

• 将玩家允许的动作纳入功能中可以显著加快早期阶段的训练速度。例如，要达到 20% 的胜率，纯粹基于棋盘的建模需要 7 小时的训练时间，而结合允许的走法可将训练时间减少到 5 小时。这与人类学习国际象棋的方法密切相关：除了理解棋盘之外，包括对可能走法的指导的辅导可以快速帮助学生发现更有效的策略。

• 在训练中后期，在训练时间相同的情况下，包含对手的允许走法比只包含自己的走法具有更高的胜率。这是因为了解对手的对策可以帮助智能体更好地理解当前情况，确保在给定的背景下做出更理性的决策。

这些观察结果凸显了细致入微的特征建模对中国象棋等战略游戏中人工智能代理的性能和效率的重大影响。

## 模型架构

对于中国象棋这样的棋盘游戏，棋盘的状态可以自然地用类似于2D图像的格式表示，表示为(H,W,C)，其中每个通道可以表示不同类型的棋子或其他信息。 ResNet 是一种最初为图像处理而设计的模型，可以很好地处理此类类型的编码信​​息。然而，在我们的训练过程中，我们发现直接使用 ResNet 的结果非常差。通过解构ResNet架构，我们发现了两种适合图像场景但不适合桌游场景的处理技术：

• 较大的内核大小，通常使用默认值(7x7)。

• 最大池化。

图像处理背景下的这些信息处理技术可以理解为帮助模型捕获图像中的关键特征，同时丢弃和合并次要细节。显然，这种方法不适合处理棋盘游戏信息，因为棋盘游戏信息中每个棋子的每一条信息都是至关重要的并且不需要合并。因此，我们通过删除最大池并将内核大小减小到 1x1 来修改传统的 ResNet。总体实验结果如表（2）所示。从这些实验观察来看，很明显，相对于基线模型的性能和预测精度都有显著提高。

当然，基于卷积神经网络 (CNN) 的派生结构在处理棋盘游戏信息时通常表现出局限性，特别是它们无法在任何给定时刻有效辨别棋盘的哪些区域更关键、哪些区域不那么关键。众所周知，基于 Transformers 的架构依赖于底层的注意力机制，可以熟练地描述战场不同区域的不同紧急程度。在这方面，我们采用了 Vision Transformer (ViT) 网络架构来处理这种类似图像的棋盘信息。从表（2）中的数据可以看出，在相同参数条件下，ViT显著提高了整体性能。值得注意的是，游戏后期的准确度大约提高了 50%。此外，与基线模型竞争时，整体胜率从 38.6% 提高到 65.1%。

## DOP 和 VECT

在本节中，我们将比较两种主要方法对强化学习训练过程有效性的影响：DOP 和 VECT。对于一般的对抗性游戏来说，可以通过强化训练过程中的自我对弈来实现迭代式的自我改进。然而，这种方法有其固有的缺点： 1. 对手模型缺乏多样性； 2. 在训练过程中，智能体逐渐忘记以前学过的策略以及对抗特定策略的方法。为了缓解这些问题，我们采用 DOP 方法。如表 X 所示，DOP 的加入增强了我们的整体训练成果，将基线模型的胜率从 84% 提高到 92.5%。

## 讨论

我们的中国象棋人工智能无需搜索的开发和验证带来了一些令人信服的发现，对强化学习（RL）方法和现实世界的应用都有影响。在这里，我们讨论这项研究的主要见解及其潜在的更广泛的影响。

另外，我们还找到了工作<sup>23</sup> 无需搜索即可研究国际象棋人工智能（不是中国象棋）。然而，这项工作的主要贡献集中在监督学习和相关结果上。

我们的研究结果为越来越多的文献做出了贡献，这些文献阐明了 Transformer 架构的多功能性和有效性。值得注意的是，从基于 CNN 的模型转换到基于 Transformer 的模型时观察到的性能改进强调了 Transformer 提供的卓越的空间关系理解。这一结果强化了这样一种观点，即注意力机制非常适合需要对输入特征进行上下文处理的任务，这表明变形金刚可以在具有复杂战略元素的游戏领域具有更广泛的适用性，甚至可能超越机器人和自主系统等领域。

通过基于规则的信息增强人工智能的功能集，显著加速和改进了学习过程。这强调了在设计学习模型的输入表示时深层领域知识的重要性。虽然这项工作的重点是中国象棋，但有可能将这种特征工程方法扩展到其他领域，在这些领域中，专家知识可以指导状态空间的表示，以帮助学习算法。

我们在训练阶段使对手策略多样化的方法凸显了传统自我对战方法的局限性，并指出需要更复杂的训练方案。使用动态对手池的概念可以作为在其他对抗性环境中开发 RL 代理的蓝图，其中任务的战略深度受益于各种策略的接触。

在 RL 阶段引入 VECT 方法，为评估回合制游戏场景中的价值函数提供了一种稳健的方法，特别是在总体奖励变化较大的情况下。这对于学习和开发国际象棋人工智能极为有利，因为它可以帮助人工智能系统更准确地预测其行为的长期利益，从而使其能够做出更好的决策。

我们的发现对游戏人工智能开发的未来具有显著的影响。通过展示在不依赖搜索算法的情况下达到高水平性能的潜力，我们为资源受限环境中更轻量级和适应性更强的人工智能铺平了道路。这种方法可能特别适用于为计算资源有限或低延迟决策至关重要的实际应用程序开发人工智能。高性能和减少计算需求的结合为重新思考游戏人工智能开发的传统方法以及更广泛背景下的决策系统提供了令人信服的理由。

尽管我们的结果很有希望，但在未来的工作中还需要解决一些限制。最值得注意的是，我们的方法应用于确定性和完美信息游戏——中国象棋。因此，我们的技术对具有随机性或不完美信息元素的游戏或场景的适用性仍有待证明。此外，人工智能的性能虽然令人印象深刻，但仍可能受益于架构设计、训练算法和特征工程的进一步改进。

总之，这项研究为强化学习领域提供了宝贵的见解，并提出了可能对一般决策系统产生影响的方法。当我们展望未来的应用和工作扩展时，本文建立的强化学习策略、模型架构和特征表示的融合无疑将为人工智能的持续发展提供信息和启发。
